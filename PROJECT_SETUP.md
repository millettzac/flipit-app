# FlipIt - Complete Project Setup Guide

**Multi-platform Resale Marketplace Mobile App**

Open-source, fully customizable, ready for app stores.

---

## What is FlipIt?

A mobile app that lets users sell items on multiple platforms simultaneously (eBay, Facebook, Shopify, etc.) with:
- AI-powered pricing recommendations
- One-click cross-platform listing
- Real-time earnings tracking
- Integrated payment processing
- Beautiful, simple design

---

## Project Components

### 1. **Mobile App** (`/web`)
- React-free HTML/CSS/JavaScript
- Works in Capacitor (iOS & Android)
- Beautiful UI with purple/pink gradient theme
- Bottom navigation (mobile-optimized)
- 4 main screens: Home, Sell, Listings, Settings

### 2. **Backend API** (`/api`)
- Node.js Express server
- Supabase PostgreSQL database
- Open-source, fully customizable
- RESTful endpoints
- JWT authentication

### 3. **Native Wrappers** (`/ios`, `/android`)
- Generated by Capacitor
- Wraps web app in native shells
- Access to device features (camera, files, notifications)
- Ready for app stores

## Getting Started (Complete Path)

### Phase 0: Initial Setup (1-2 hours)
```bash
# 1. Install Node.js
# Visit: https://nodejs.org/

# 2. Navigate to project
cd C:\Users\mille\OneDrive\Desktop\Obsidian\codes\FLIPIT_APP

# 3. Install web dependencies
npm install

# 4. Install API dependencies
cd api
npm install
cd ..
```

### Phase 1: Local Development (2-3 hours)
```bash
# 1. Set up Supabase
# Visit: https://supabase.com
# Create project → Get credentials

# 2. Configure environment
cd api
cp .env.example .env
# Edit .env with your Supabase credentials

# 3. Create database
# Copy migrations/001_init_schema.sql into Supabase
# Execute it

# 4. Start API locally
npm run dev
# API runs at http://localhost:5000
```

### Phase 2: Mobile Development (2-3 hours)
```bash
# 1. Add iOS platform
npm run cap:add:ios

# 2. Update web app to use local API
# Edit web/index.html
# Change API_BASE_URL to http://localhost:5000

# 3. Open Xcode
npm run cap:open:ios

# 4. Build and test in simulator
# Product → Build → Run
```

### Phase 3: Deployment Prep (4-6 hours)
```bash
# 1. Deploy API to the internet
# Choose: Railway, Heroku, DigitalOcean, or AWS
# See DEPLOYMENT_GUIDE.md

# 2. Update app with deployed API URL
# Edit web/index.html
# Change API_BASE_URL to your deployed URL

# 3. Build final app
npm run cap:sync

# 4. Archive for app stores
# iOS: Product → Archive in Xcode
# Android: Build → Make Project in Android Studio
```

### Phase 4: App Store Submission (1-2 days for approval)
```
1. Create Apple Developer Account ($99/year)
2. Create Google Play Developer Account ($25 one-time)
3. Submit iOS build to App Store
4. Submit Android build to Google Play
5. Wait for approval (24-48 hours each)
6. LIVE! 🎉
```

## Important Notes

### 1. Database Schema
The PostgreSQL schema includes tables for:
- Users (profiles, settings)
- Listings (items for sale)
- Platform connections (eBay, Facebook, Shopify links)
- Orders (sales tracking)
- Payouts (earnings)
- Analytics (user events)

**All data is secured with Row-Level Security (RLS) policies.**

### 2. API Endpoints
Currently implemented:
- `/auth/register` - Create account
- `/auth/login` - Login
- `/listings` - Get/create/update/delete listings
- `/users/:id` - Profile management
- `/users/:id/platforms` - Platform connections

Full list in `api/API_DOCS.md`

### 3. Security
- Passwords hashed with bcryptjs
- JWT tokens for authentication
- CORS protection
- SQL injection prevention (Supabase ORM)
- Row-Level Security in database

### 4. Customization
Everything is customizable:
- Colors (currently purple #8B5CF6, pink #EC4899)
- Fonts (Poppins)
- Endpoints (add/modify in `api/server.js`)
- Database schema (modify `migrations/001_init_schema.sql`)
- UI (modify `web/index.html`)

## Common Issues & Solutions

### "API not connecting"
1. Check `.env` variables in `api/.env`
2. Verify Supabase project is active
3. Confirm CORS is enabled
4. Check network tab in browser DevTools

### "Database migration failed"
1. Verify Supabase connection
2. Check SQL syntax in migration file
3. Ensure all dependencies are installed
4. Check PostgreSQL user permissions

### "App store rejection"
1. Missing privacy policy → Add to settings
2. Unclear functionality → Better description
3. Buggy experience → Test thoroughly
4. Wrong category → Update in app store config

### "Can't find npm packages"
```bash
# Clear cache and reinstall
rm -r node_modules
npm cache clean --force
npm install
```
